What changed since v0.1.0. The README and `docs/theme-api.md` describe each feature in full.

## New

- **Before-install programs**: a `[[run]]` with `at = "before-install"` runs before any file is
  staged, after the running app is closed, in windowed and `--silent` installs alike. It names
  payload files as `{payload}\<path>`, which the installer extracts first and `silk build` checks
  exist; use it to remove an older installer's install, say one made by electron-builder's NSIS.
  A failure leaves the installed version as it was.
- **WebView2 bootstrapper**: `webview2_bootstrapper = true` packs Microsoft's bootstrapper into the
  installer (about 1.8 MB), which runs it when the WebView2 runtime is missing, then shows its window.
- **Missing WebView2 runtime**: the installer says so, gives the address of Microsoft's download
  page and exits, before asking for administrator rights; `--silent` installs anyway.
- **Windows Firewall**: `[[firewall]]` sections add inbound allow rules on install and remove them on
  uninstall, per-machine installers only.
- **Talking programs**: a `[[run]]` with `talk = true` sends the theme each line it prints and its
  exit code, and the theme writes to its stdin with `silk.write`.
- **`silk.openUrl`** opens a web address in the user's default browser.
- **`silk.reboot()`** restarts Windows and starts the installer again after sign-in, with
  `silk.info.resumed` set, for an install that needs a restart.
- A per-user installer starts the app it closed again if the install later fails, and a
  `{payload}\` path matches its file as Windows does: either slash, any case.

## Hardening

- Every `unsafe` block states why it is sound, and archive offsets and Win32 sizes are converted
  with checked conversions rather than lossy casts.
- cargo-deny checks the advisories and licences of every dependency an installer redistributes;
  Dependabot updates them weekly.
- Formatting, clippy with warnings denied, and caps on function complexity and nesting are checked
  on every change, in CI and before each merge.
