What changed since v0.2.0. The [README](https://github.com/tome-vtt/silk-setup/blob/v0.2.1/README.md)
and [theme API](https://github.com/tome-vtt/silk-setup/blob/v0.2.1/docs/theme-api.md) describe each feature in full.

## New

- **Shortcut app identity (`AppUserModelId`)**: set `app_user_model_id = "..."` under `[shortcuts]`
  to put the same identity on every shortcut the installer writes. Match the identity the app sets
  for itself so Windows groups its pinned taskbar icon with its running app and shows its
  notifications. (SILK-S41-T1)
- **Cancel running programs**: `silk.cancel()` ends a running `[[run]]` program and whatever it
  started, so a theme can cancel an install while a program runs. Once the phase is `finishing`,
  it stops only an after-install program; an uninstall still cannot be cancelled. (SILK-S28-T1)
- **Window creation errors**: if the installer cannot create its window, it reports the failure
  instead of panicking. (SILK-S23-T1)

## Hardening

- Windows system tools run by their System32 paths, and bare-name `[[run]]` programs resolve from
  the system folder, avoiding programs planted in the working directory or on `PATH`.
  (SILK-S32-T1, SILK-S38-T1)
- Complexity checks reject attempts to silence the complexity and nesting lints, including through
  lint groups or `warnings`; cognitive complexity measurement stops at the trailing test module.
  The agent instructions explain both caps and their shrink-only baselines. (SILK-S6-T2)
- Dependabot opens security-update pull requests only; Spider's weekly catch-up ticket handles
  version updates. (SILK-S43-T1)
